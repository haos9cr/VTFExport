# VTF Export language file template (all strings in English).
#
# Two ways to use a translation:
#  a) Built into the plug-in: put the file into the project's lang\ folder
#     (e.g. lang\pl.lang) and rebuild. Check it with: python tools/check_lang.py
#  b) Without rebuilding: put it into the VTFExport_lang folder next to VTFExport.8bi.
#     A file there with the same language.code as a built-in language only
#     overrides the strings it contains.
#
# Set language.name (shown in the list) and language.code, translate the values.
# Keys you delete fall back to English. Encoding: UTF-8, extension: .lang.
# \n = line break. {w}, {error}, ... are placeholders and must stay as they are.
