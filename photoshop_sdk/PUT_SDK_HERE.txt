Put the Adobe Photoshop C++ SDK (Windows) here, so that this file exists:

    photoshop_sdk\pluginsdk\photoshopapi\photoshop\PIFormat.h

Download: https://developer.adobe.com/developer-console/ -> APIs and services ->
Photoshop Plug-In and Connection SDK (free, Adobe ID required).
The SDK may not be redistributed, so it is not part of the repository.
